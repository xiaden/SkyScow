# Task: Pin and Synchronize the Sleev Gateway

## Problem Statement

The image currently installs an unpinned Sleev CLI and relies on the CLI/wrapper
to arrange a gateway at runtime. That conflicts with the container's s6
supervision model and makes persistent volumes retain stale or malformed gateway
installations. This plan implements the approved S6-preserving update: ship the
verified Sleev CLI and gateway 1.6.16 at build time, synchronize that immutable
image artifact into the persistent gateway layout during root entrypoint startup,
and leave s6 responsible for running the gateway directly.

This is one plan and has no CONTRACTS.md dependency. Do not touch
`config/instructions/i_have_adhd.md`, which contains unrelated user changes.
